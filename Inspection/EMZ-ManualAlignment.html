EMZ Manual Align · 3 weld

Manual Align กับ 3 weld

align ตามลำดับ weld 1 → weld 3 → weld 2 · ตัวเลขเป็นค่าสมมติ (1 record ≈ 2 mm, tolerance ±300 mm ≈ 150 record, signature เป็น hash จำลอง)

ลำดับ: weld 1→weld 3→weld 2
weld ข้อมูลอื่นในแถบ ตำแหน่งที่คลิก ref ของ weld

ขั้นปัจจุบัน

Anchors

eventId Weld Group offsetMm clickRecord ref shift

ทีละขั้น

  1. รายละเอียด

    การเหลื่อมของ G0 / G1 / G2 / G3:

    weld 1 (true 80): +30 / +70 / +110 / 0 weld 2 (true 340): +20 / +90 / +130 / 0 weld 3 (true 540): +40 / +60 / +100 / 0

    weld 2 ไม่ได้อยู่บนเส้นตรงระหว่าง weld 1 กับ weld 3 จึงต้องคลิกเพิ่ม

  2. รายละเอียด
    • ยังไม่มี anchor clickRecord = 110 → event ใหม่ eventId 0
    G0: (110, +0)
  3. รายละเอียด
    • ห่าง G0 (110) 40 rec ≈ 80 mm → eventId 0, ref 110 → +40
    G1: (110, +40)
  4. รายละเอียด
    • ห่าง G1 (150) 40 rec → eventId 0, ref 110 → +80
    G2: (110, +80)
  5. รายละเอียด
    • clickRecord = 80 → ref ของ eventId 0 เปลี่ยนจาก 110 เป็น 80
    • shift: G0 +30, G1 +70, G2 +110, G3 0
    • แต่ละ group มีจุดเดียว shift จึงคงที่ทั้งไฟล์ weld 2 และ 3 เลื่อนด้วยค่าเดียวกันแต่ไม่ตรง
  6. รายละเอียด
    • G0 ถูกเลื่อน +30 weld 3 ของ G0 จึงแสดงที่ 550 → EmzManualAlignRawRecord: 550 + 30 = 580
    • คลิกที่ใกล้สุด (190) ห่าง 390 rec ≈ 780 mm → event ใหม่ eventId 1
    • ระหว่าง 80 ถึง 580 shift ของ G0 ลดจาก +30 เป็น 0 แบบเส้นตรง
    G0: (80, +30), (580, +0)
  7. รายละเอียด
    • ห่าง G0 ของ weld 3 (580) 20 rec → eventId 1, ref 580 → +20
    G1: (80, +70), (580, +20)
  8. รายละเอียด
    • ห่าง G1 (600) 40 rec → eventId 1, ref 580 → +60
    G2: (80, +110), (580, +60)
  9. รายละเอียด
    • ref ของ eventId 1 เปลี่ยนจาก 580 เป็น 540 → shift ที่ weld 3: +40, +60, +100, 0
    • weld 2 ได้ shift จาก interpolation (G0 ≈ +35, G1 ≈ +64, G2 ≈ +104) แต่เหลื่อมจริง +20, +90, +130 จึงยังไม่ตรง: G0 ≈ 325, G1 ≈ 366, G2 ≈ 366, G3 340
    G0: (80,+30) (540,+40) G1: (80,+70) (540,+60) G2: (80,+110) (540,+100) G3: (80,+0) (540,+0)
  10. รายละเอียด
    • shift ที่ column 325 มาจาก interpolation: 30 + round(245 / 460 × 10) = 35 → clickRecord = 360 ถ้าไม่บวกจะได้ 325 ซึ่งผิด
    • ห่าง weld 1 (190) 170 rec และ weld 3 (540) 180 rec เกิน 150 ทั้งคู่ → eventId 2
    • ShiftTable เรียงจุดตาม ref (std::sort) จุดของ weld 2 จึงแทรกตรงกลาง
    G0: (80, +30), (360, +0), (540, +40)
  11. รายละเอียด
    • ใกล้ G0 ของ weld 2 (360) 70 rec มากกว่า weld 3 (540) 110 rec → eventId 2, ref 360 → +70
    G1: (80, +70), (360, +70), (540, +60)
  12. รายละเอียด
    • ใกล้ G1 ของ weld 2 (430) 40 rec มากกว่า weld 3 (540) 70 rec → eventId 2, +110
    G2: (80, +110), (360, +110), (540, +100)
  13. รายละเอียด
    • ref ของ eventId 2 เปลี่ยนจาก 360 เป็น 340 → shift ที่ weld 2: +20, +90, +130, 0
    • จุดของ weld 1 และ 3 ไม่เปลี่ยน
    G0: (80,+30) (340,+20) (540,+40) G1: (80,+70) (340,+90) (540,+60) G2: (80,+110) (340,+130) (540,+100)
  14. รายละเอียด
    • ผลสุดท้ายเหมือนคลิก 1 → 2 → 3 เพราะ EmzManualAlignShiftTable::Build เรียงจุดตาม ref
    • ลำดับมีผลแค่ภาพระหว่างทาง และ eventId ที่นับตามลำดับคลิก
    • ตอนคลิก weld กลาง ต้องบวก shift ที่ interpolate อยู่ (EmzManualAlignRawRecord)
    • ป้าย W1..Wn ในหน้า Property ของโปรแกรมจริงอาจเรียงต่างจากนี้ ยังไม่ได้ตรวจกับโค้ด
